# Acheron Payload Toolkit

**Windows payload generator with Acheron direct syscalls for Defender evasion.**

Generates staged Meterpreter payloads (`windows/x64/meterpreter/reverse_tcp`) with Acheron direct syscalls for Windows Defender evasion. Includes automated listener with UAC bypass (Method 59 - Debug Object / PPID Spoofing).

## Features

- **Staged Meterpreter payload** (`windows/x64/meterpreter/reverse_tcp`) - Small shellcode (~511 bytes), stealthy
- **Acheron direct syscalls** - Bypasses userland API hooking by EDR/AV
- **Acheron-based EXE** - PE32+ x64, 1.8 MB, direct syscalls (NtAllocateVirtualMemory, NtWriteVirtualMemory, NtCreateThreadEx)
- **UAC Bypass (Method 59)** - Debug Object / PPID Spoofing via ComputerDefaults.exe
- **Automated listener** - msfconsole resource script with auto-alias for manual UAC bypass
- **TUI interface** - Interactive menu for payload generation
- **Verbose by default** - Use `-q` for quiet mode

## UAC Bypass (Method 59 - Debug Object / PPID Spoofing)

The toolkit includes a complete UAC bypass implementation:

1. **Listener** creates alias `bypassuac` automatically on new session (`InitialAutoRunScript`)
2. **Manual trigger** in meterpreter: `bypassuac`
3. **Process:**
   - Generates new Acheron payload with random name
   - Uploads to victim `%TEMP%`
   - Executes `uacbypass.exe` (Method 59 - Debug Object / PPID Spoofing)
   - Spawns new session as **NT AUTHORITY\SYSTEM**
4. Listener remains active (`ExitOnSession false`)

### Requirements for UAC Bypass
- `uacbypass.exe` compiled from `uacbypass.c` (included)
- Deploy on victim: `C:\Windows\Temp\uacbypass.exe`
- Compile: `x86_64-w64-mingw32-gcc uacbypass.c -o uacbypass.exe -static`
